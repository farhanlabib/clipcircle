# Security

ClipCircle carries whatever you copy, so security reports matter a lot.

Please report a vulnerability privately through
[GitHub's private vulnerability reporting](https://github.com/farhanlabib/clipcircle/security/advisories/new)
rather than in a public issue. Include the steps to reproduce it and what an
attacker could do. You'll get an answer as soon as possible, and credit in the
fix's release notes if you want it.
